# Data

Nothing in this folder is committed except this file. Use it as a local working area.

- **Shared copies** live in private Kaggle Datasets and the shared Google Drive folder (see the README's "Where outputs live").
- **Never commit** report PDFs, model files, generated answers or gold labels.
- **Gold labels** stay in their own store, which only evaluation code reads.
- **Every dataset** gets a note of its source, version and licence in the decision log when it is first downloaded (phase 2).
